# E-scape

2023 Unity Game Project: E-scape

게임 개요:

- 게임 시작 시 학습할 주제를 지정

- ChatGPT를 통해 해당 주제에 대한 짧은 지식들(단서)을 얻어 와 저장

- 플레이어는 맵을 이동하면서 단서가 담긴 오브젝트를 수집

- 모두 수집한 이후 그 주제에 대해 퀴즈를 응시

- 일정 점수를 넘길 시 점수를 획득

개발에서 수행 역할:

- 게임에서 어떤 맵을 사용할지 계획

    - 좁은 면적에 많은 오브젝트가 배치되는 맵 2가지(저택, 연구실 테마)를 선정

- 맵의 시각적 요소를 보완(프롭 배치 등)

- 맵 내 단서 오브젝트 배치 알고리즘 구현

    - 주변 프롭이나 오브젝트와의 거리를 계산해 적절한 위치에 자동으로 배치

- 맵과의 상호작용 구현(문 열기 등)
